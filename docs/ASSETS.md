# Ассеты

## Происхождение

Исходники перенесены из текущей коллекции пользователя. Оригиналы `001–083.tgs` сохранены без изменений. PNG-превью оригиналов взяты из ранее подготовленной папки `png_frame_03`.

Стоячая коллекция использует геометрию позы `002` и оформление моделей `034–083`. Сердечки удалены, руки опущены. Модель `061` намеренно остаётся серым силуэтом, как исходник.

## Каталог

`public/catalog.json` содержит `schemaVersion`, `modelCount`, `poses`, `models`.

- `previewUrl`, `vectorUrl`, `referenceUrl` — URL относительно корня будущего приложения, раздающего папку `public`.
- `sourceFile` — путь относительно корня проекта к оригинальному TGS; не публичный URL.
- `sha256` — контрольные суммы соответствующих файлов.
- `poseId: "002"` — текущая готовая стойка.
- Идентификаторы — строки с ведущими нулями, например `"034"`.

## Векторные версии

Lottie JSON имеет холст 512×512, один статичный кадр и исходные векторные пути, заливки и градиенты. Исходные файлы остаются статичными. При добавлении модели редактор настраивает 2D-точки вращения конечностей в src/core.js; маски и детали вращаются вместе с соответствующими руками и ногами. Это базовая артикуляция, без сгибания локтей и коленей или новых ракурсов.

Структура слоёв может отличаться между моделями. Дополнительные детали используют маски, поэтому произвольное изменение порядка слоёв может испортить узоры и повязки. При настройке поз необходимо двигать связанные элементы вместе.

PNG предназначены для каталога и просмотра. Для будущего изменения поз использовать векторные версии и оригиналы TGS.

## Граница текущей подготовки

В проект перенесены готовые ассеты. Старые экспериментальные скрипты, зависящие от абсолютных путей предыдущей рабочей папки, сюда не включены. `scripts/build_catalog.py` проверяет коллекцию и строит каталог; он не перерисовывает модели.
