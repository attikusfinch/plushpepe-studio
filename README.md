# Plush Pepe Studio

Небольшой браузерный редактор для композиций с Plush Pepe, стикерами и картинками.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm install
npm run dev
```

Откройте **http://127.0.0.1:5180**. Встроенные стикеры подготавливаются автоматически перед запуском.

Для сборки: `npm run build`. Готовое приложение находится в `dist`; его можно разместить на статическом хостинге. Для подпапки задайте PAGES_REPOSITORY с именем подпапки перед сборкой. `npm run preview` открывает собранную версию локально.

## Возможности

- Библиотека 50 стоячих Пепе `034–083`.
- Мастерская лица: отдельные глаза, пуговицы и улыбка; сдвиг, наклон, размер и отражение. Крупный план рядом с образцом `002`, быстрые правки и отдельный экспорт модели в PNG.
- Шесть готовых поз, настройка углов и режим «Кости»: по три перетаскиваемые точки на каждой руке и ноге. Векторные контуры, повязки и узоры сгибаются вместе с конечностями.
- 83 встроенных анимированных стикера с выбором кадра и предпросмотром движения.
- Импорт PNG, JPG, WebP, GIF, SVG, AVIF, TGS, Lottie JSON, WebM и MP4. Перетаскивание файлов на холст и вставка картинок из буфера обмена.
- Выбор кадров для TGS/Lottie, GIF и анимированного WebP; выбор момента видео с шагом 1/30 секунды.
- Перемещение, масштабирование, поворот, отражение, прозрачность, дублирование, переименование и удаление объектов.
- Слои: изменение порядка перетаскиванием или кнопками, скрытие и блокировка.
- Текст, цветной или прозрачный фон, размер холста от 64 до 4096 px по каждой стороне.
- Экспорт PNG и JPG в размере 1× или 2×. Прозрачные области в JPG становятся белыми.
- Отмена и повтор действий, автосохранение на устройстве, сохранение и открытие `.plush.json` вместе с импортированными файлами.

На первом запуске открывается редактируемая демонстрационная композиция. Пустой холст: **Холст → Новый пустой холст**.

## Управление

Нажмите на модель в библиотеке, чтобы добавить её. На холсте перетаскивайте объект; ручки рамки меняют размер и поворот. Свойства и позы — справа. Верхний слой в списке рисуется поверх остальных.

Для ручного сгиба выберите Пепе и нажмите **Кости** или **B**. Всего 12 точек: **1** — крепление (переносит всю конечность), **2** — локоть/колено, **3** — кисть/стопа. Перетаскивайте их прямо на холсте. Один жест — один шаг отмены. Изгибы сохраняются в проекте и учитываются в PNG/JPG; сами точки в экспорт не попадают. «Сбросить изгибы» возвращает исходную форму, сохраняя углы. Готовый пресет позы сбрасывает ручные изгибы.

- `Ctrl / ⌘ + Z` — отменить; `Ctrl / ⌘ + Shift + Z` — повторить.
- `Ctrl / ⌘ + D` — дублировать выбранный слой.
- `Ctrl / ⌘ + S` — скачать проект.
- `Delete` — удалить; стрелки — сдвинуть на 1 px, с Shift — на 10 px.

## Как устроено

Приложение работает локально в браузере; файлы не отправляются на сервер. Проект автоматически сохраняется в IndexedDB текущего браузера. Для переноса на другое устройство или надёжной копии скачайте `.plush.json`.

- React + Vite — интерфейс и сборка.
- Konva — холст, выделение и трансформации.
- Lottie SVG — векторные модели и стикеры, включая маски. Версия движка без выполнения выражений.
- pako — распаковка TGS; gifuct-js и ImageDecoder — кадры GIF/WebP.
- Шрифт поставляется вместе с приложением.

`src/core.js` — структура проекта и позы; `src/rig.js` — деформация контуров и координаты костей; `src/BoneHandles.jsx` — управление точками; `src/media.js` — импорт, кадры и экспорт; `src/Canvas.jsx` — холст; `src/App.jsx` — редактор; `src/storage.js` — локальное сохранение.

Исходные TGS находятся в `assets/sources/tgs`. Скрипт `scripts/prepare-assets.mjs` копирует их в генерируемую папку `public/stickers` перед запуском и сборкой. Исходные TGS и векторные модели сохранены без изменений. PNG-превью моделей показывают актуальное стандартное лицо.

## Текущие границы

Позы и изгибы работают с 2D-векторными деталями. Точки позволяют свободно растягивать и сгибать конечности без ограничений длины костей; при сильном изгибе возможны пересечения. Новые ракурсы и поворот головы требуют дополнительного рисунка. Экспорт этой версии — статичные PNG/JPG; экспорт анимации в TGS пока не реализован.

Рекомендуется настольный Chrome или Edge. Для выбора кадров анимированного WebP нужен ImageDecoder; доступные видеокодеки зависят от браузера. PNG/AVIF импортируются как изображения. Lottie JSON должен содержать встроенные картинки, если они используются. Один импортируемый файл — до 40 МБ; композиция — до 200 слоёв.

## Проверки для разработки

```sh
npm test
npm run test:browser
```

Браузерные сценарии используют установленный Chrome на Windows или браузер Playwright. В другой среде можно выполнить `npx playwright install chromium`; свой исполняемый файл задаётся через `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

Проверка исходной коллекции: `python scripts/build_catalog.py` (Python 3.10+, без дополнительных библиотек).

## GitHub Pages

Workflow `.github/workflows/pages.yml` автоматически собирает и публикует приложение при пуше в `main`; также доступен ручной запуск в Actions.

В **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**. Для приватного репозитория Pages должен поддерживаться тарифом аккаунта; переводить репозиторий в публичный автоматически workflow не будет.

Адрес после успешного деплоя: **https://attikusfinch.github.io/plushpepe-studio/**.

Workflow сам задаёт путь проекта. Он публикует только `dist` с библиотекой моделей и стикеров; пользовательские проекты и импортированные файлы остаются в браузере. Для переноса композиции с localhost на сайт сохраните `.plush.json` и откройте его на сайте: это разные хранилища браузера.

Локальная сборка с тем же путём в PowerShell:

```powershell
$env:PAGES_REPOSITORY='plushpepe-studio'
npm run build
Remove-Item Env:PAGES_REPOSITORY
```

## Мастерская лица

Выберите Пепе → **Лицо модели → Редактировать лицо**. Выберите глаз, пуговицу или улыбку справа; перемещайте рамку на крупном плане, меняйте размер за уголки и наклон за верхнюю ручку. Доступны точные поля сдвига, наклона, размера и зеркальное отражение.

«Глаза на одном уровне», «Пуговицы левее» и «Улыбка ровнее» применяются по умолчанию ко всей коллекции. Верхние веки слегка прикрывают глаза, как в образце 002, и используют контур и цвет обводки модели. Выберите глаз и настройте **Верхнее веко**: 0% открывает глаз, 60% сильнее прикрывает; стандарт — 30%. Кнопка «Вернуть стандартное лицо» возвращает эти настройки. Уже сохранённые ручные правки имеют приоритет; новые веки добавляются автоматически, если их значение ещё не задано. Лево и право указаны как на картинке. Тени двигаются вместе с соответствующей деталью, пуговицы — вместе со своим глазом, сохраняя возможность отдельной правки.

Перед применением выберите область: только эта фигура или модель целиком. Во втором случае обновляются незаблокированные копии этой модели в сцене; настройка сохраняется для новых копий и в новых проектах этого браузера. `.plush.json` содержит параметры лица и настройки моделей для переноса на другое устройство. Оригинальные TGS/PNG при этом не перезаписываются; у настроенных моделей в библиотеке появляется отметка. Для получения отдельного исправленного файла используйте **PNG модели** (стоячая поза, 512×512, прозрачный фон).

Модель `061` — силуэт без отдельных деталей лица; мастерская для неё отключена.

Для обновления PNG-превью после изменения стандартного лица запустите локальный сервер, затем `npm run previews` (по умолчанию порт 5180). Другой адрес: `npm run previews -- http://127.0.0.1:5173/`; путь к Chrome можно задать через `CHROME_PATH`.
