# Plush Pepe Studio

Редактор Plush Pepe: выбор модели, настройка позы и экспорт результата.

## Что уже готово

- 50 стоячих моделей `034–083` в позе `002`: PNG 512×512 с прозрачным фоном.
- Послойные векторные версии этих моделей в формате Lottie JSON.
- 83 оригинальных TGS и их PNG-превью для работы с моделями и позами.
- Каталог ассетов `public/catalog.json` и общий лист `docs/models-overview.png`.

Интерфейс Studio ещё не реализован. Векторные модели сейчас содержат один статичный кадр; для произвольных поз нужно настроить суставы, точки вращения, связи деталей и перекрытия.

## Структура

```text
assets/sources/tgs/              Оригиналы 001–083, без изменений
public/references/              PNG-превью оригиналов 001–083
public/models/standing/png/     50 готовых стоячих моделей
public/models/standing/lottie/  50 послойных векторных моделей
public/catalog.json            Каталог моделей и исходной позы
docs/models-overview.png        Общий лист моделей
docs/ROADMAP.md                 План разработки редактора
docs/ASSETS.md                  Формат и особенности ассетов
scripts/build_catalog.py       Проверка ассетов и сборка каталога
```

Папка проекта самостоятельная: файлы из родительской папки для работы с каталогом не нужны.

## Проверка ассетов

Требуется Python 3.10 или новее, без сторонних библиотек:

```sh
python scripts/build_catalog.py
```

Команда проверяет комплектность файлов, размеры PNG, чтение TGS и структуру Lottie, затем обновляет каталог.

## Дальше

Подключить созданный репозиторий и отправить туда проект. Затем собрать первый экран: каталог моделей, холст и выбор позы. План — в `docs/ROADMAP.md`.
